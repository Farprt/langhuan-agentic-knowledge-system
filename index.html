LOCAL-FIRST · OBSIDIAN-NATIVE · AGENT-READY

让 Agent 在你的知识库中，找到与任务相关、可以核对的上下文。

Langhuan 是面向 Obsidian / Markdown 项目的本地优先知识库工具：检索笔记正文、定位已有文件，并为 Agent 准备本次任务需要阅读和检查的内容。

5 分钟了解项目 查看知识库示例

公开知识库提供目录和工作流示例；其他 Markdown 目录可通过一个配置文件接入。

工作流程

从知识库配置到 Agent 调用

配置文件定义知识库范围，命令行返回检索结果和任务上下文，本地事件记录执行状态。

01 / CONFIG

知识库配置

一个 langhuan.toml 描述目录、YAML 字段、检索范围和非敏感运行选项。

  • Obsidian 结构化解析
  • 项目级检索范围
  • 路径与配置可移植

02 / TASK

Agent 任务上下文

命令行先定位目标文件，再返回应阅读文件、处理方式和必须检查的项目。

  • 稳定 CLI / JSON
  • 正文来源可以核对
  • 索引完整写入后再替换旧版本

03 / RUN

本地运行记录

JSONL 记录步骤、状态与耗时；AgentLoop 和 Langfuse 只是可选分析出口。

  • 云端故障不阻塞任务
  • 正文采集默认关闭
  • 导出与检索分离

核心能力

解析、检索与增量维护

公开版本提供演示知识库和自动测试；实际生产环境已运行在数千个知识片段的私人知识库中。

解析

理解 Obsidian，而不只是读取纯文本

YAML 元数据、双向链接、嵌入引用和标题层级都会保留在知识片段中。

检索

语义与关键词结果分开生成、统一排序

语义向量与 BM25 结果经 RRF 融合，再由可选本地交叉编码器二次排序；默认 Hash 后端只用于离线演示。

可靠性

只更新发生变化的文件

文件哈希用于识别新增、修改和删除；索引完整写入后再替换旧版本，并检查知识片段 ID 是否一致。

项目验证

57 项自动测试全部通过
离线 demo无需模型或云账号
一致性检查解析 / 增量 / 删除 / 隐私

公开仓库包含演示知识库、测试代码和可复现的命令。

数据边界

知识内容和索引默认保留在本地

DEFAULT

默认留在本地

原始 Markdown、本地索引、模型缓存和 JSONL 事件；凭据不会写入项目配置或导出事件。

按需启用

外部分析与长期记忆

AgentLoop 和 Langfuse 由显式命令按需导出；Honcho 仅提供集成约定，由外部 Agent 写入稳定结论。

不提交

本地敏感文件

私有知识、真实日志、数据库、模型缓存、凭据和第三方二进制不会提交到 Git。

实现范围

核心模块与可选服务

核心模块

Obsidian 解析、按标题分块、混合检索、增量同步、文件结构索引、任务上下文、本地运行记录与一致性检查。

可选能力

可加载已准备好的本地 BGE 和交叉编码器模型；运行记录可按需导出到 AgentLoop 或 Langfuse，Honcho 集成按约定由外部 Agent 完成。
